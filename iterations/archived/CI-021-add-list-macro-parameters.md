# Iteration CI-021: Add List Macro Parameters

**Target Capability:** `/capabilities/macros/capability.md`

## User Story
As a Trellis author, I want to pass a list of values or objects to a macro (`List items="item 1","item 2","item 3"`) and repeat part of the macro body for each of them (`Each $items as=item`) so that a macro can render any number of items, such as a menu or a list of cards, from one argument.

Read the `CI-021` entries in the Product Decisions, Technical Decisions, Syntax and Data Dictionary of the target capability before starting, and the entries they extend (`CI-017 Argument values (planned)`, `CI-017 Parameters can be used anywhere (planned)`, `CI-017 Substitution (planned)`, `Unlabeled argument $1`, the `CI-019` object parameter entries and `CI-020 Pointer arguments for macros (planned)` in `/capabilities/data-references/capability.md`).

## Acceptance Criteria
1. `src/web/syntax/macros.ts`: an argument can be a list. Elements are separated by `,` with no spaces and are quoted (which may contain `,`, `|` and spaces) or bare (no spaces, `"` or `,`); quotes are stripped when stored; a value with no comma outside quotes is a list of one, and a bare element starting with `@` is a pointer as before. This applies to plain named arguments and the unlabeled `$1`. Dotted object-field arguments stay a single value. A source without lists or `Each` is expanded exactly as before (a source with no `Def` is still returned as the very same string).
2. `Each $param as=name` in a `Def` body repeats its children (the lines indented 2 spaces deeper) once per element, at the `Each` line's indentation, with `$name` replaced by the element anywhere a `$name` may appear. The `Each` line itself produces no output. `Each` over `$1`, nested `Each` over different parameters, macro uses and core lines inside an `Each`, and passing the element on (`Inner label="$item"`) all work. A single value runs once.
3. Lists of objects: an object parameter takes records separated by `,` in the piped form (`Cards items="A"|"a text","B"|"b text"`), and inside `Each $items as=card` the fields are `$card.title` and `$card.description`. A single record still works without `Each` and the dotted form is one record.
4. A list can be passed whole to another macro as the bare value of an argument (`Inner items=$items`), keeping all its values, so it can go through several macros.
5. `Each` is a reserved macro name (`Macro name "Each" is reserved`) and the loop variable exists only inside its `Each`.
6. The new errors are produced fail-fast, prefixed `Line <n>: `, with exactly these messages: `Invalid Each "<text>" (expected Each $param as=name)`; `Each in macro "<macro>" has no children`; `Name "<name>" is already used in macro "<macro>"`; `Unknown parameter "$<name>" in macro "<macro>"` (a looped parameter that is not declared, or a loop variable used outside its `Each`); `Argument "<name>" is a list (use it in an Each)` (and `Argument "1" is a list ...` for `$1`); `Each can only be used in a macro body`; and `Invalid argument "<token>" (expected name=value or name="value")` for an empty element such as `items=a,,b`. Errors keep the line mapping of `CI-017 Error lines (planned)`.
7. `parseSyntax`, `compileSyntax`, the AST schema and the line mapping are unchanged.
8. The seed of the global macros (`seedMacrosSource` in `src/web/macros/api.ts`) also defines `Def List $items` (a `Box` containing an `Each $items as=item` with a `Text "$item"` per item) and its `Examples` page also shows `List items="Reports","Settings","Help"`. `PageTitle` and `Field` and their uses are unchanged. The seed compiles without error, and no seeded feature wire frame defines `List`.
9. Tests (`pnpm test`, DOM-free as before): `src/web/syntax/macros.test.ts` gets a `list parameters` group covering list parsing (quoted, bare, mixed, a quoted element with `,` and `|`, a single value, an empty `""` element, pointers, `$1` lists, bare values that now split on a comma), `Each` expansion (indentation, nesting, several first-level children, macro uses inside, passing the element on, a single value, the loop variable scope), lists of objects (several records, one record, the count error per record, the dotted form staying single), passing a list on with `Inner items=$items`, and every error in criterion 6 with its exact message and line. `src/web/macros/api.test.ts` and `src/web/macros/macro-editor.test.tsx` are updated for the new seed (it compiles and the preview shows the list items).
10. `pnpm test`, `pnpm typecheck` and `pnpm build` pass.
11. Updates `README.md` only if it describes macro parameters (keep it a short feature mention), and logs the implementation decisions in the Product Decisions or Technical Decisions of `/capabilities/macros/capability.md` (the `(planned)` `CI-021` entries are confirmed or amended by `CI-021 ... implementation` or `behaviour` entries; old entries stay as history).
